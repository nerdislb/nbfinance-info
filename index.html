What this project is

nbfinance is a private software prototype for a local, read-only overview of Giro account balances. Development and verification currently use explicitly synthetic data.

An account balance is not a spending allowance. Card obligations and other reservations must be accounted for before a complete budget can be claimed.

What this website is not

This is an information-only site. It does not offer account login, bank authorisation, payment initiation, application downloads or a callback endpoint. It contains no financial snapshots, bank credentials or finance-application source code.

Never enter bank details here or add tokens, authorisation codes or financial information to these URLs. Future bank authorisation must use a separately configured official provider and bank flow.
