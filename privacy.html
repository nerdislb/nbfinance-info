Draft — preparation only

Do not use these drafts for live bank registration. Operator identity and final application processing remain pending. The public privacy/security contact below is approved, but this page is not a completed privacy policy for live bank-data processing.

Scope of this notice

This page describes the current public information website, not a hosted finance application. The website consists of static HTML and CSS. It has no account system, contact form, banking input, payment flow, application analytics script, advertising or third-party asset embeds.

The website itself does not run client-side code that sets cookies or browser storage. This statement does not describe or limit processing performed by GitHub's hosting infrastructure.

Hosting by GitHub Pages

GitHub Pages serves this website. GitHub documents that it logs and stores visitors' IP addresses for security purposes, including visits made without signing into GitHub.

Read the GitHub Pages data-collection documentation and the GitHub Privacy Statement for the hosting provider's processing and retention information. This project does not promise a particular retention period for GitHub's infrastructure records.

No banking intake on this website

No authorisation callback is hosted here. Do not put bank account details, balances, passwords, tokens, authorisation codes or financial snapshots into page URLs, public repositories or public comments.

Opening these information pages does not connect an account or authorise a bank-data retrieval. External links lead to separate sites with their own privacy information.

Planned private application

The finance prototype is separate from this website and currently verified with synthetic data. Any future live connection needs an explicitly configured provider and bank authorisation.

Before live use, the operator must finalise the applicable identity/contact details, processing purposes and legal basis, provider roles, data categories, storage and retention, security measures, consent/revocation handling and rights/contact process for the actual configuration. These details are not asserted as settled by this draft.

Privacy and security contact

The approved public contact for privacy and security matters is security@nbsystems.dev.

Do not send bank passwords, PINs, TANs, card numbers, account identifiers, financial snapshots or authorisation codes by email. This static website does not transmit or store email messages; contact-message processing and the operator's identity still need to be specified in the final notice.

Approval of this contact address does not finalise this draft or authorise live bank-data processing.
