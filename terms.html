Draft — preparation only

Do not use these drafts for live bank registration. Final application processing remains pending. The public privacy/security contact is approved, but these notes do not establish a public banking service or a final agreement for live account access.

Operator

Bernhard Slatinsek · Private household project.

Information-only website

No live banking service is offered here. This website publishes general project information; it has no user registration, bank login, payment initiation, account-data upload, hosted finance dashboard or application-download flow.

The private application is a separate prototype. No account access or payment is authorised by viewing these pages.

Prototype limitations

Development and verification currently use synthetic data. Results are not a guarantee that a particular bank feed is complete, current or correctly mapped. Live integrations, device deployment and secure transfer need their own verification.

A booked account balance is not a spending allowance. Unconnected card obligations, pending transactions, fixed costs and a reserve can make the amount actually available to spend lower. Do not infer a complete household budget from a partial view.

These pages do not provide personal financial or investment advice.

Keep sensitive information private

Do not submit passwords, PINs, TANs, card numbers, account identifiers, financial snapshots, API keys or authorisation codes to this public website, repository or any public discussion. This information site is not a bank-authorisation callback.

Any future bank authorisation must be an explicit action in the separately configured official provider and bank flow.

Finalisation before live use

The operator must review and approve the actual service scope, identity/contact information, provider configuration, privacy description and applicable usage terms before using the project with live bank data. No account access, billing or provider acceptance is promised by this draft.

No software licence for the private finance application is granted by this information website.
